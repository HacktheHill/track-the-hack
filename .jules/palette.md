## 2025-01-20 - Use type="search" for Search Inputs
**Learning:** Adding the `type="search"` attribute to search `<input>` fields improves the mobile user experience significantly. It triggers the native mobile search keyboard rather than the standard text keyboard, and it often provides built-in browser functionality like native clear (`x`) buttons without requiring custom JS or CSS.
**Action:** When adding or modifying search inputs across the application, always ensure they have the `type="search"` attribute applied.
