## 2025-01-20 - Add type="search" to search inputs
**Learning:** Adding the `type="search"` attribute to text inputs intended for searching provides native browser functionality like clear buttons and triggers mobile search keyboards, improving the UX and accessibility without requiring custom JS/CSS.
**Action:** When adding or modifying search inputs, always apply the `type="search"` attribute to trigger native mobile search keyboards and built-in browser clear buttons without requiring custom JS or CSS.
