## 2024-05-15 - Add type="search" to search inputs
**Learning:** Adding `type="search"` to text inputs intended for searching not only provides better semantics but also triggers native mobile search keyboards and built-in browser clear buttons automatically without requiring custom JS or CSS.
**Action:** Always verify search inputs in Next.js or React applications contain the `type="search"` attribute to improve mobile UX and leverage native browser features.
