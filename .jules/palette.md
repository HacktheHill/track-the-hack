## 2025-02-12 - Native search input type
**Learning:** Adding `type="search"` to search `<input>` fields provides a better mobile experience by triggering native search keyboards and displaying a built-in "clear" button in the browser.
**Action:** When adding or modifying search inputs, always apply the `type="search"` attribute to trigger native mobile search keyboards and built-in browser clear buttons without requiring custom JS or CSS.
