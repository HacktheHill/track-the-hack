
## 2024-10-21 - Native Search Inputs for Better UX
**Learning:** Using `type="search"` instead of `type="text"` or omitting the type for search inputs natively triggers specialized mobile search keyboards (with "Search" or "Go" buttons instead of "Return") and provides built-in browser features like the clear ("x") button without requiring custom JavaScript or CSS.
**Action:** Always apply the `type="search"` attribute to inputs meant for filtering or searching lists, especially since this application features hardware catalogues likely to be searched from mobile devices on-the-go.
