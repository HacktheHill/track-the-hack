## 2024-05-23 - Add type="search" to search inputs
**Learning:** Adding `type="search"` to search `<input>` fields improves UX by triggering native mobile search keyboards and providing built-in clear buttons in browsers, making search experiences more intuitive without needing custom JavaScript or CSS.
**Action:** Always add `type="search"` when implementing or updating search fields to enhance usability out-of-the-box.
