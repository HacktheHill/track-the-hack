## 2026-09-24 - Memoizing Synchronous Operations in the Render Phase
**Learning:** Found a recurring anti-pattern where expensive synchronous array operations (`.filter`, `.find`, `.sort`) are executed directly in the render phase of React components, especially top-level pages receiving TRPC queries. The `schedule/index.tsx` was recalculating derived fields like `displayed`, `active`, and `next` unnecessarily because they lacked memoization, while variables like `now` changed every minute, potentially causing lag or unexpected behavior.
**Action:** When implementing derived states that depend on component state or query data, always wrap them in `useMemo` hooks with strict and accurate dependency arrays (e.g., `[visible, tab]`, `[displayed, now]`). Never leave complex data manipulation in the main body of a functional component without it, as the render pass can be triggered by unrelated state updates.
