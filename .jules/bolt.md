## 2025-02-23 - Expensive Array Operations in Render\n**Learning:** Next.js pages often perform expensive array operations (filter, sort, reduce) directly in the render cycle instead of wrapping them in useMemo. The `qr` and `schedule` pages are particularly affected. Memoizing array results without explicit timer intervals when filtering with `Date.now()` can break reactivity.\n**Action:** Extract expensive synchronous array operations in render phase to `useMemo`. When filtering based on time, use state and `setInterval` for updating current time.
