## 2024-03-24 - Memoizing Time-based Arrays in React Component Renders
**Learning:** In top-level page components (like the schedule view receiving tRPC query data), expensive array operations (`.filter`, `.sort`, `.reduce`) involving the current time (`Date.now()`) are an anti-pattern when executed directly in the main render phase, causing continuous layout thrashing or sluggish renders. However, naively wrapping these operations in `useMemo` with `Date.now()` directly evaluated inside causes components to become entirely frozen in time because it breaks React's dependency tracking for auto-updating components.
**Action:** When memoizing derived lists that filter on the current time (e.g. expiring events), declare a separate `now` state variable and increment it periodically using `setInterval` inside a `useEffect`. Then, make the `useMemo` block depend on `now` to achieve optimized performance without breaking time-reactivity.
