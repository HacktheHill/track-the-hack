## 2024-03-24 - Memoizing array operations in React components
**Learning:** O(n) array operations like `.filter()`, `.sort()`, and `.map()` inside a component's render body can cause significant performance bottlenecks, especially when working with moderately large data sets (like a schedule of events). When memoizing these operations with `useMemo`, it's critical to include implicit or periodic dependencies, like the current timestamp (`now`), in the dependency array to ensure the UI updates correctly over time.
**Action:** When finding expensive array operations in the render cycle, move them into `useMemo` hooks before the render block. Always check for implicit dependencies like `Date.now()` (or a state variable updating periodically) to preserve auto-updating behaviors.
