## 2024-05-18 - Expensive Synchronous Calculations in Top-Level React Render Phase
**Learning:** Top-level React components receiving TRPC queries (like pages retrieving event data) can suffer from a performance anti-pattern where expensive synchronous array operations (`.filter`, `.sort`, `.reduce`) and string formatting (e.g., `Date.toLocaleDateString`) run continuously directly in the render phase for non-primitive data types.
**Action:** When working on top-level pages receiving queries that need formatting/sorting, wrap these derived data calculations in `useMemo` hooks to prevent recalculation on every re-render. Additionally, be careful of implicit temporal dependencies within these loops, such as `Date.now()`. Memoizing will break their auto-updating behaviors unless they are replaced by a state variable (`currentTime`) that is updated periodically via `setInterval`.
